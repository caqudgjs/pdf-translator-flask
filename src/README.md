# PDF 번역기

이 프로젝트는 AI를 기반으로 PDF 형식의 학술 논문을 전문적으로 번역하는 웹 애플리케이션입니다. 사용자는 PDF 파일을 업로드하고 OpenAI API 키를 이용하여 원하는 언어로 번역된 결과를 얻을 수 있습니다.

## 주요 기능

- **PDF 파일 번역**: PDF 파일을 업로드하여 텍스트를 추출하고 번역합니다.
- **OpenAI 모델 선택**: GPT-4o Mini, GPT-4o 등 다양한 OpenAI 모델을 선택하여 번역 품질을 조절할 수 있습니다.
- **용어집 제공**: 번역문과 함께 전문 용어에 대한 용어집을 제공합니다.
- **한국어 음독 생성**: 전문 용어의 한국어 발음을 자동으로 생성하여 가독성을 높입니다.
- **간편한 인터페이스**: 드래그 앤 드롭 방식의 파일 업로드 등 사용자 친화적인 UI를 제공합니다.

## 사용 방법

1.  웹 페이지에 접속합니다.
2.  번역할 PDF 파일을 업로드 영역으로 드래그하거나 클릭하여 선택합니다.
3.  자신의 OpenAI API 키를 입력합니다. (API 키는 서버에 저장되지 않습니다.)
4.  번역에 사용할 OpenAI 모델을 선택합니다.
5.  '번역 시작' 버튼을 클릭합니다.
6.  번역이 완료되면 번역문과 용어집을 확인할 수 있으며, 결과를 다운로드하거나 복사할 수 있습니다.

## 기술 스택

-   **백엔드**: Python, Flask
-   **프론트엔드**: HTML, CSS, JavaScript
-   **AI 모델**: OpenAI API (GPT-4o Mini, GPT-4o 등)

## 자주 묻는 질문 (FAQ)

**Q: API 키는 안전하게 관리되나요?**  
A: 네, 입력하신 OpenAI API 키는 서버에 저장되지 않으며, 번역 요청 시에만 일시적으로 사용됩니다.

**Q: 번역 가능한 PDF 용량 제한이 있나요?**  
A: 네, 현재 최대 50MB까지의 PDF 파일만 업로드할 수 있습니다.

**Q: 번역에 시간이 얼마나 걸리나요?**  
A: 번역 시간은 PDF 파일의 페이지 수, 텍스트의 양, 그리고 선택한 AI 모델에 따라 달라질 수 있습니다. 일반적으로 몇 분 정도 소요될 수 있습니다.

**Q: 번역 품질은 어떤가요?**  
A: 번역 품질은 선택하는 OpenAI 모델에 따라 달라집니다. GPT-4o와 같은 최신 모델을 사용할수록 더 자연스럽고 정확한 번역 결과를 얻을 수 있습니다.

**Q: 오류가 발생하면 어떻게 해야 하나요?**  
A: 먼저 API 키가 올바르게 입력되었는지, 유효한 키인지 확인해 주세요. 문제가 지속되면 PDF 파일의 형식이 올바른지, 인터넷 연결이 안정적인지 확인해 보시기 바랍니다.

**Q: 용어집은 어떻게 생성되나요?**  
A: AI 모델이 논문의 핵심 주제와 문맥을 분석하여 전문 용어를 식별하고, 해당 용어에 대한 적절한 한국어 번역과 설명을 자동으로 생성합니다.
