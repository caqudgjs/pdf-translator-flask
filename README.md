# PDF 번역기 (PDF Translator)

AI 기반 PDF 번역 웹 애플리케이션입니다. 이 프로젝트는 OpenAI GPT 모델을 사용하여 PDF 문서를 한국어로 번역합니다. 특히, 논문과 같은 전문적인 문서의 번역 품질을 높이기 위해, **핵심 전문 용어**를 일관된 형식으로 번역하고 별도의 **용어집**을 생성하는 데 중점을 둡니다.

## 주요 기능

- **특수 형식 번역**: 모든 전문 용어를 `한국어번역(원문, 한글음독)` 형식으로 번역하여 가독성과 명확성을 높입니다.
- **문맥 인식 번역**: AI가 전체 문맥을 파악하여 자연스럽고 유창한 번역문을 생성합니다.
- **자동 용어집 생성**: 번역이 완료된 텍스트에서 특수 형식으로 처리된 모든 용어를 역추적하여 용어집을 자동으로 만듭니다.

## 동작 원리 (How it Works)

이 번역기는 안정성과 정확성을 위해 **강력한 단일 프롬프트를 기반으로 한 2단계 프로세스**로 동작합니다.

1.  **PDF 텍스트 추출**: `PyPDF2` 라이브러리를 사용하여 업로드된 PDF 파일에서 전체 텍스트를 추출합니다.
2.  **텍스트 분할**: 추출된 텍스트를 GPT API의 최대 토큰 길이에 맞게 여러 개의 조각(chunk)으로 나눕니다.
3.  **1단계: 번역 수행**: 각 텍스트 조각을 매우 상세하고 구체적인 규칙이 포함된 '단일 실행(One-shot)' 프롬프트와 함께 GPT API에 전송합니다. AI는 이 프롬프트의 지시에 따라, 전문 용어를 `한국어번역(원문, 한글음독)` 형식으로 즉시 변환하며 전체 텍스트를 자연스러운 한국어로 번역합니다.
4.  **2단계: 용어집 추출**: 모든 조각의 번역이 완료되면, 합쳐진 전체 번역문을 다시 한번 GPT API에 보냅니다. 이번에는 번역문에 포함된 `한국어번역(원문, 한글음독)` 형식의 단어들을 모두 찾아내어 구조화된 JSON 형식의 용어집을 생성하도록 요청합니다.
5.  **결과 표시**: 최종 번역문과 여기서 추출된 용어집을 사용자에게 함께 보여줍니다.

이 방식은 복잡한 코드 로직 대신 잘 설계된 프롬프트에 의존하여, 안정성을 유지하면서도 사용자가 원하는 정교한 결과물을 만들어냅니다.

## 파일 구조

-   `requirements.txt`: 프로젝트 실행에 필요한 파이썬 라이브러리 목록.
-   `src/main.py`: Flask 애플리케이션을 실행하는 메인 파일.
-   `src/routes/pdf_translate.py`: `/api/pdf/translate` API 엔드포인트를 정의하고 번역 요청을 처리하는 라우터.
-   `src/pdf_translator_requests.py`: PDF 텍스트 추출, API 호출, 번역 및 용어집 추출 등 모든 핵심 로직을 포함하는 주 번역기 모듈.
-   `src/static/`: 프론트엔드(HTML, CSS, JavaScript) 파일.

## 요구사항

- Python 3.8 이상
- pip

## 설치 방법

1.  **프로젝트 클론 또는 다운로드**

2.  **가상 환경 생성 및 활성화**

    ```bash
    # Python 가상 환경 생성
    python -m venv venv

    # Windows
    venv\Scripts\activate

    # macOS / Linux
    source venv/bin/activate
    ```

3.  **필요한 라이브러리 설치**

    ```bash
    pip install -r requirements.txt
    ```

## 애플리케이션 실행

1.  **Flask 개발 서버 시작**

    ```bash
    python src/main.py
    ```

2.  서버가 시작되면 터미널에 다음과 같은 메시지가 표시됩니다.

    ```
     * Running on http://127.0.0.1:5000
    ```

## 사용 방법

1.  웹 브라우저를 열고 `http://127.0.0.1:5000` 주소로 접속합니다.
2.  번역할 PDF 파일을 업로드합니다.
3.  유효한 OpenAI API 키를 입력합니다.
4.  '번역 시작' 버튼을 클릭합니다.
5.  번역이 완료되면 결과가 화면에 표시되며, 번역문과 함께 자동으로 생성된 용어집을 확인할 수 있습니다.
